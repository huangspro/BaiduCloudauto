# 百度网盘 SVIP 多人共用的方法

百度网盘的限速是众所周知的。企图依赖各种脚本破解并获取文件的直接下载链接是很难的，因为行代码会不断更新。最稳定的方法是购买 **SVIP**（目前下载速度已经可达 **20MB/s**）然后多人使用。

然而 **SVIP 登录设备有限**，了解到百度网盘的各种上传下载等操作，可以使用百度网盘开放平台提供的 **API** 自动完成。那么可以考虑一种想法。

首先需要一个**超级 SVIP 用户**，不妨把她叫为 **Alice**。根据百度网盘开放平台的规则，你在开放平台上申请一个应用，然后获取一些应用凭证。再通过应用凭证获取一个叫做 **access_token** 的东西。凭借这个 access_token，就可以使用百度网盘开放平台的 API 完成各种网盘操作。同时，这些操作是享有 SVIP 的。

然后 Alice 自己创建了一个**服务器 A**，下面是工作流程。

> 网盘 --- 服务器 A --- 多个用户

用户提交一个分享链接，这个链接中包含一些文件。用户提交的这个链接会被传送到**服务器 A**。

服务器 A 已经部署好了各种能够自动完成百度网盘操作的程序，并且调节程序使用的 **API Key** 已经 **SVIP**。

有两种方案：然后这个服务器自动将分享的链接保存到自己的网盘，并且启动下载。下载完成后将文件返回给用户。这样可以将同一个文件传输两次。另一种方式是，服务器将获取的下载链接发送给用户，并且将一个 **access_token** 也发过去。根据百度网盘的规则，只要这个 access_token 的主人是 **SVIP**，那么我下载就能够获得 **SVIP 速度**。

下面具体介绍百度网盘开放平台操作流程

---

## 1. 创建应用

在百度开放平台上创建一个应用，通过认证。创建完这个应用后，打开百度网盘电脑版，就能够看见多了一个文件夹 **“我的应用数据/应用名”**，这个就是我们的 API 能够控制的文件夹。

---

## 2. 获取 access_token

无论做任何事情都必须要持有 **access_token**，所以首先要获取 access_token。

1. 获取 **authoritation_code**。
2. 通过 authoritation_code 获取 **access_token**。
3. 第二步同时会得到一个 **refresh_token** 的东西。refresh_token 的有效期是 **10 年**，可以用来刷新 access_token，因为 access_token 有效期只有 **30 天**，30 天后就会失效。所以必须要不断刷新。有了 refresh_token，就不用每次都要 authoritation_code 了。

---

## 3. 下载

1. 获取 **fs_id**，fs_id 是每一个文件独一无二的 ID。
2. 通过 fs_id 获取 **dlink**，也就是下载链接。
3. 通过 dlink 下载文件。如果 Alice 是普通用户而不是 **SVIP 会员**，那么通过这个 dlink 下载是会限速的。是 **SVIP 会员**则不会限速。
