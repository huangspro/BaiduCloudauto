# 百度网盘 SVIP 多人共用的方法

百度网盘的限速是众所周知的。企图依赖各种脚本破解并获取文件的直接下载链接是很难的，因为行代码会不断更新。最稳定的方法是购买 SVIP（目前下载速度已经可达 20MB/s）然后多人使用。

然而 SVIP 登录设备有限，了解到百度网盘的各种上传下载等操作，可以使用百度网盘开放平台提供的 API 自动完成。那么可以考虑一种想法。

---

## 一、 基本想法

* **超级 SVIP 用户**：不妨把她叫为 **Alice**。
* **规则与凭证**：
  * 根据百度网盘开放平台的规则，你在开放平台上申请一个应用，然后获取一些应用凭证。
  * 再通过应用凭证获取一个叫做 `access_token` 的东西。
  * 凭借这个 `access_token`，就可以使用百度网盘开放平台的 API 完成各种网盘操作。
  * 同时，这些操作是享有 SVIP 的。

---

## 二、 流程

Alice 自己创建了一个服务器 A：

> **网盘** $\longleftrightarrow$ **服务器 A** $\longleftrightarrow$ **多个用户**

### 工作流程：
1. **提交链接**：
   * 用户提交一个分享链接，这个链接中包含一些文件。
   * 用户提交的这个链接会被传送到服务器 A。
2. **自动化程序**：
   * 服务器 A 已经部署好了各种能够自动完成百度网盘操作的程序，并且调节程序使用的 API Key 已经 SVIP。
3. **保存与下载**：
   * 这个服务器自动将分享的链接保存到自己的网盘，并且启动下载。
   * 下载完成后将文件返回给用户。
   * 这样可以将同一个文件传输两次。根据百度网盘的规则，只要这个 `access_token` 的主人是 SVIP，那么我下载就能够获得 SVIP 速度。

---

## 三、 一点想法

注意：这里很明显，所有事情都是在服务器中完成的，用户只是得到了最终的文件。我们可以把一些事情搬到客户端上进行。比如我们可以：

1. **优化设想 1**：将最终的下单链接和 `access_token` 拼接成完整的下载链接后发给用户。
2. **优化设想 2**：甚至我们可以一开始就将 `access_token` 发给客户端，然后客户端自己完成文件查找、解析链接、下载全部过程。

### 遗憾的是：

* **第 1 点是不可行的**：
  * 因为 Alice 自己的百度网盘空间是有限的。
  * 某一个用户下载完某一个文件之后，就必须把这个文件从网盘上删掉，不然文件就会越积越多。
  * 是我们只把链接发给用户，我们并不知道用户是在什么时候下载完成的。
  * 而且可能用户根本就没有下载。

* **第 2 点是不可行的**：
  * 因为 Alice 自己的百度网盘空间是有限的。
  * 某一个用户下载完某一个文件之后，就必须把这个文件从网盘上删掉，不然文件就会越积越多。
  * 如果我们把下载链接或者 `access_token` 直接交给所有用户。
  * 他们就有可能同时使用这些 `access_token` 将各种大文件保存到网盘里，网盘空间会瞬间耗尽。
  * 所以我们必须要自己控制这个过程，使网盘空间不至于耗尽。

---

## 四、 百度网盘开放平台具体操作流程

### 1. 创建应用与认证
* 在百度开放平台上创建一个应用，通过认证。
* 创建完这个应用后，打开百度网盘电脑版，就能够看见多了一个文件夹“`我的应用数据/应用名`”（实际路径与显示路径不一样，实际是apps/应用名），这个就是我们的 API 能够控制的文件夹。

### 2. 获取与维护 `access_token`
无论做任何事情都必须要持有 `access_token`，所以首先要获取 `access_token`：
* （1）获取 `authoritation_code`。
* （2）通过 `authoritation_code` 获取 `access_token`。
* （3）第二步同时会得到一个 `refresh_token` 的东西。`refresh_token` 的有效期是 10 年，可以用来刷新 `access_token`，因为 `access_token` 有效期只有 30 天，30 天后就会失效。所以必须要不断刷新。有了 `refresh_token`，就不用每次都要 `authoritation_code` 了。

### 3. 文件下载
* （1）获取 `fs_id`，`fs_id` 是每一个文件独一无二的 ID。
* （2）通过 `fs_id` 获取 `dlink`，也就是下载链接。
* （3）通过 `dlink` 下载文件。如果 Alice 是普通用户而不是 SVIP 会员，那么通过这个 `dlink` 下载是会限速的。是 SVIP 会员则不会限速。
