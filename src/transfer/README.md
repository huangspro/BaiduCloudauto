# 百度网盘文件自动转存项目说明

## 项目来源

- 原始项目：[BaiduPanFilesTransfers](https://github.com/hxz393/BaiduPanFilesTransfers.git)
- 功能：将他人百度云链接中的文件自动转存到我自己的 `apps/` 文件夹中

## 背景说明

由于百度云 API 的使用限制，自动转存操作并非免费。因此，我们需要使用从百度云网站捕获的 **cookie** 来进行控制。

## 代码修改说明

对原始代码进行了以下修改：

1. **移除 UI 部分**：UI 对我们的项目并不必要，因此将其移除。
2. **封装为函数**：将核心逻辑封装成一个函数，以便在项目的其他地方调用。

## 使用方式

修改后的代码以函数形式提供，调用该函数即可完成自动转存操作（需传入从百度云网站捕获的 cookie）。
